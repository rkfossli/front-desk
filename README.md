# Front Desk

A phone game told entirely through the messaging app of a night guard's desk phone. Prototype engine and story data.

- `index.html` at the root is the single-file build served by GitHub Pages: https://rkfossli.github.io/front-desk/
- `prototype/index.html` is the engine, `prototype/story.js` the story data (the single-file build inlines the latter).
- `planlegging/` holds the story bible, fact book, image list and review reports (Norwegian).

Test settings inside the game: long-press the clock in the status bar (or press D on a keyboard).
